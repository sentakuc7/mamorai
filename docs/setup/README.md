# MamorAI のセットアップ（AI に読ませる手順書）

MamorAI の手順書は、人が 1 行ずつ打ち込む前提ではありません。**利用者が普段使っている AI**（Claude・ChatGPT・Gemini など）に読み込ませ、「これを手伝って」と頼んで進める作りです。AI は、画面の操作を案内したり、コマンドを代わりに実行したりします。

| 順番 | 手順書 | 内容 | 利用者が手でやること |
|---|---|---|---|
| 1 | [01-prepare-tailscale.ai.md](01-prepare-tailscale.ai.md) | Tailscale のアカウントを作り、使い回せる認証キーを発行する（持ち出し PC・外部のサーバーを守る場合だけ） | ブラウザでの登録とキーの発行 |
| 2 | [02-setup-mamorai.ai.md](02-setup-mamorai.ai.md) | Wazuh と MamorAI を 1 台のサーバーに構築し、Tailscale のキーと登録パスワードを MamorAI に登録する | キーを 1 回入力する、最初の管理者を作る |
| 3 | [../agent-pack.md](../agent-pack.md) | 端末用のエージェントパックを DL して配る | 解凍して実行するだけ |

## 設計の約束

- 利用者に敷居の高い作業（OAuth の設定など）はさせない。
- Tailscale は必須ではない。「つなぎ方」は LAN だけ・Tailscale・公開アドレスから選ぶ。
- 秘密情報（Tailscale のキー・登録パスワード）は 1 回入れれば MamorAI が暗号化して持ち、エージェントパックに自動で入る。パックは暗号化 ZIP で配り、端末でインストールが終わると自動で消える。
- 手順書の中の AI は、パスワードやキーを画面やチャットに出さない。

今後の予定: 02 の手順は、1 本のセットアップスクリプト（EDR-91）にまとめる。
