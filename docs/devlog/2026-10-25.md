# Dev update — 2026-10-25

*日本語は下にあります / Japanese below*

## Shipped this week

- 🛡 **Self-defense for MamorAI itself** — TOTP MFA (no external service, QR enrolment, recovery codes), login throttling, step-up approval with a 6-digit code for high-risk actions, and a **kill switch** that halts every autonomous action at once. MamorAI's own logs are now ingested by Wazuh with dedicated detection rules.
- 📦 **Agent pack** — one zip per OS (Windows / Linux) that both installs a new agent and updates an existing one. The pack is versioned (r1, r2, …) whenever its contents change, verified by SHA-256, and MamorAI shows which hosts are running an old pack. Registration passwords and Tailscale keys are never bundled by default.
- 🔍 **AI host scan (in progress)** — collects what a host *is*: exposed services, installed software, logged-in users, and how it is actually used, then summarizes it into a per-host "chart". Read-only, fixed command list, every AI statement must cite evidence.

## Next

- **Act from the host page** — stop service / block port / block IP / isolate host, all approval-gated with one-click revert. Wazuh and MamorAI itself can never be blocked; an isolated host keeps its Wazuh channel.
- **v0.1 (attack map only)** — target late November. `docker compose up` → attack map on your own Wazuh data.

## 今週入れたもの

- 🛡 **MamorAI 自身の防御** — TOTP の MFA（外部サービス不要、QR 登録、リカバリーコード）、ログイン回数制限、リスクの高い操作は 6 桁コードでステップアップ承認、そして AI の自動実行を一括で止める**緊急停止ボタン**。MamorAI 自身のログも Wazuh に取り込み、専用の検知ルールを追加。
- 📦 **エージェントパック** — Windows / Linux それぞれ 1 つの zip で、新規導入も更新も同じ手順。中身が変わると版（r1, r2, …）が上がり、SHA-256 で改ざんを検知。どのホストが古いパックのままかを MamorAI 側で表示。登録パスワードや Tailscale のキーは既定で同梱しない。
- 🔍 **ホストを AI でスキャン（実装中）** — 提供しているサービス、入っているソフト、ログインしているユーザー、使われ方を集めて、ホストごとの「カルテ」にまとめる。読み取り専用・固定コマンドのみ・AI の記述には必ず根拠 ID を付ける。
