# Dev update — 2026-11-04

*日本語は下にあります / Japanese below*

## Shipped since 10-25

- 🧰 **Act from the host page** — stop a service, block a port, block a remote IP, or isolate the host. Every action goes through the approval queue (human-in-the-loop), and Linux network changes revert automatically after 3 minutes unless you confirm them, so a bad rule can't lock you out. Windows actions run through Wazuh's active response. Wazuh and MamorAI itself are always on the protected list; an isolated host keeps its Wazuh channel. Every action is audited and can be posted to Discord.
- 🔍 **AI host scan → host chart** — finished. Exposed services, installed software, users and how the host is actually used, summarized per host with evidence IDs. A scheduled re-scan raises an alert on meaningful changes (a new listening port, a new admin user, remote-access software). The AI also suggests a role note and tags for each host; you apply them with one click and it won't re-suggest what you've already decided.
- 📦 **Installer prototype** — `install.sh` tested end-to-end on a clean Ubuntu 24.04. Tailscale is now an optional module, and the keys the agent pack needs are stored encrypted inside MamorAI instead of being typed on the download screen.
- 🧭 **Easier to read** — proposal cards in Sidekick now sit in one horizontally scrolling row so the chat stays visible, and the dashboard / alert wording was unified for non-specialists (raw Wazuh counts moved to the detailed view).
- 🖥 **tools/lcd** — the attack map on a 3.5" USB sub-monitor (published in this repo).

## Next

- 🧪 **Forensics (design done)** — look *back* through Windows event logs with Hayabusa, run a lightweight memory scan (hollowed / injected processes, YARA), and overlay the results on Wazuh's own detections as one incident timeline with an AI summary that cites evidence. Rules are kept up to date and distributed signed, without an extra installer.
- 🩹 **Windows patching from Sidekick** — Windows Update and winget, with the reboot as a separate approval.
- **v0.1 (attack map only)** — still targeting late November. `docker compose up` → attack map on your own Wazuh data.
