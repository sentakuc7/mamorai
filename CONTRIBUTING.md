# Contributing / 貢献について

このリポジトリは **凍結版（アーカイブ）** です。MamorAI（Wazuh 版）の開発はここで終わっており、次の版は別に開発しています。

- **Pull Request は受け付けていません。** 送られても取り込みません（閉じます）。
- 不具合の報告やご意見は Issues に書いていただいてかまいませんが、修正や返信は約束できません。
- セキュリティ上の問題は Issues に書かず、[SECURITY.md](SECURITY.md) の方法で連絡してください。
- フォーク（AGPL-3.0 の範囲での改変・再配布）は自由です。

This repository is a **frozen (archived) edition**. Development of MamorAI for Wazuh has ended here; the next generation is developed separately.

- **Pull requests are not accepted** and will be closed without merging.
- You may open issues for bugs or feedback, but fixes and replies are not guaranteed.
- Report security problems as described in [SECURITY.md](SECURITY.md), not in public issues.
- Forks under the terms of AGPL-3.0 are welcome.
