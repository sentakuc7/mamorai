# Contributing / 貢献について

MamorAI（Wazuh 版）は一区切りの安定版です。新しい機能の開発は次の MamorAI（別の作り）に移っており、この版では不具合やセキュリティの修正を必要に応じて行います。

- **Pull Request は受け付けていません。** 送られても取り込みません（閉じます）。
- 不具合の報告やご意見は Issues にどうぞ。修正は必要に応じて行いますが、時期は約束できません。
- セキュリティ上の問題は Issues に書かず、[SECURITY.md](SECURITY.md) の方法で連絡してください。
- フォーク（AGPL-3.0 の範囲での改変・再配布）は自由です。

MamorAI for Wazuh has reached a stable milestone. New feature work has moved to the next MamorAI (a separate codebase); this edition receives bug and security fixes as needed.

- **Pull requests are not accepted** and will be closed without merging.
- Issues for bugs and feedback are welcome. Fixes are made as needed, without a fixed timeline.
- Report security problems as described in [SECURITY.md](SECURITY.md), not in public issues.
- Forks under the terms of AGPL-3.0 are welcome.
